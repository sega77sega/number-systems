# Перевод систем счисления

Маленькая страница, которая переводит число между двоичной, восьмеричной,
десятичной и шестнадцатеричной системами счисления. Всё в одном файле,
без сборки, зависимостей и интернета.

## Зачем

Пригодится на информатике и просто чтобы быстро проверять себя, когда
считаешь переводы вручную.

## Как запустить

Открыть `index.html` двойным кликом в любом браузере. Всё.

## Как пользоваться

1. Ввести число в поле «Число».
2. Выбрать систему счисления, в которой это число записано.
3. Ниже появятся значения во всех четырёх системах сразу.

Недопустимый для выбранной системы символ подсвечивается ошибкой.
Например, `2` в двоичной системе.

## Как устроено

- `parseInBase` разбирает строку посимвольно и собирает число через
  умножение на основание. Используется `BigInt`, поэтому длинные числа
  не теряют точность.
- `toBase` делит число на основание и собирает остатки в обратном порядке.
- `render` вызывается на каждое изменение поля и перерисовывает таблицу.
